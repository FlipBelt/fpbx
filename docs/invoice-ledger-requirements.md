# 发票自动归档同步需求清单

## 范围说明

本清单只覆盖审批成功后的“发票自动归档同步”模块。报销主流程、付款截图金额核验、审批表单提交和其他定时审批能力不在本模块的交付范围内。

## 功能需求

| 编号 | 需求 | 验收口径 | 状态 |
| --- | --- | --- | --- |
| FR-01 | 审批成功触发归档 | 每个审批实例最多产生一个幂等归档事件；重复触发不重复写台账 | 已完成 |
| FR-02 | 附件角色分流 | 只有发票附件进入台账；付款截图、行程单和订单页不作为发票行 | 已完成 |
| FR-03 | OCR 快照标准化 | 支持增值税发票、数电发票、铁路客票；保存票种、来源、质量和异常 | 已完成 |
| FR-04 | 月份路由 | 使用审批发起月份；目标月登记缺失时停止写入并提示补录 | 已完成 |
| FR-05 | 字段映射 | 按 A:M 13 列固定契约写入，空值保持空值，不虚构字段 | 已完成 |
| FR-06 | 去重 | 按发票号码、销方识别号、价税合计和内容指纹去重；疑似重复进入人工确认 | 已完成 |
| FR-07 | 异常记录 | 保存审批编号、事件、状态、原因代码、字段缺失和处理时间 | 已完成 |
| FR-08 | audit 模式 | 完整运行提取、去重和审计，但不创建、更新或清空钉钉工作簿 | 已完成 |
| FR-09 | sync 模式 | 写入前备份，写入后逐批回读；任何校验失败都停止并回滚 | 已完成，需灰度 |
| FR-10 | 部分成功 | 记录已写入行、未完成字段和人工处理原因，不把部分成功伪装成成功 | 已完成 |
| FR-11 | 审批级回滚 | 仅在行未被人工修改且 M 列为空/“否”时自动清空，否则转人工 | 已完成 |
| FR-12 | 历史审计与补录 | 支持从原审批附件或已有 OCR 快照恢复；补录前预览，写后回读 | 已完成 |
| FR-13 | 失败可追踪 | 原件不可读、快照缺失、关键字段缺失、金额关系不一致均可按原因检索 | 部分完成：需补充更细根因分类 |
| FR-14 | 月度台账校验 | 登记的工作簿 ID、文档标识、工作表和 13 列表头与实际钉钉文档一致 | 已验证至 2026-09 |

## 安全与数据完整性要求

| 编号 | 要求 | 验收口径 | 状态 |
| --- | --- | --- | --- |
| NFR-01 | 默认保守运行 | 本地和生产配置显式声明 `mode`；未获确认不得切换到生产 `sync` | 本地已显式 `audit`，生产为 `audit` |
| NFR-02 | 不绕过关键字段门槛 | 发票号码、金额、价税合计和契约要求字段不足时不写入 | 已完成 |
| NFR-03 | 不绕过去重 | 重复或指纹冲突不得为了提高写入数而强行写入 | 已完成 |
| NFR-04 | 可恢复 | 每次 sync/补录保存写前备份、批次状态和回读证据 | 已完成 |
| NFR-05 | 保护敏感信息 | 日志、聊天和测试输出不得包含私钥、token、Cookie、完整配置或完整环境变量 | 持续约束 |
| NFR-06 | 外部调用可控 | 优先复用 OCR 缓存、历史 JSON 和本地解析器；不得无必要重复调用付费 OCR | 持续约束 |
| NFR-07 | 生产操作可审计 | 生产核验默认只读；重启、配置切换和写入需有明确操作记录 | 持续约束 |
